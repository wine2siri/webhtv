# T18.1 追更意图分离

## 用户语义

- 收藏：表示喜欢或保存内容，不等于资源订阅。
- 追更：表示希望看到未看更新，可独立取消，不删除心愿或网盘文件。
- 心愿：表示搜索、订阅和管理资源，不自动进入追更；旧行为可在后台显式开启。
- 最新集在前：只改变剧集展示顺序，连续播放仍按集数递增，例如 129 → 130。

## 客户端交互

- 追更卡片短按直接进入可播放详情。
- 追更卡片长按打开追更菜单，可加入/取消追更、置顶、设置最新集在前。
- 剧集顺序按规范化片名持久化，切换 Emby 来源后继续生效。
- 电视端和手机端共享相同的展示与连播语义。

## 兼容边界

- 后端 `nav_config.tracking_include_tv_wishlist` 默认 `false`。
- 只有显式开启后，电视剧心愿才作为兼容来源进入追更聚合。
- 取消追更不取消订阅，也不删除网盘文件。
