# T18 全局内容安全过滤

## 目标

在首页、分类和搜索的最终卡片入口统一移除成人/情色、低幼/儿童与 LGBT 主题内容，不依赖每个第三方站源自行实现过滤。

## 设计依据

- 站源协议返回的字段完整度不一致；客户端能稳定取得标题、类型、备注和简介。
- 过滤放在 `SiteApi` 解析完成之后，可覆盖 type 0/1/3/4 以及蜘蛛、本地包和 CMS 源。
- 影卓追剧后端仍使用 TMDb 类型 ID + 关键词的更强策略；客户端作为所有第三方源的最终兜底。

## 取舍

- 未采用逐站修改：容易漏源，后续新增源也不会自动继承。
- 未过滤详情与播放接口：避免已进入详情页的正常播放链路被意外改变。
- 第三方源若只给模糊标题且完全不提供类型/简介，客户端无法可靠判断；不会用封面图像识别来猜测内容。

## 验收

1. 首页、分类、搜索三条路径均调用统一过滤器。
2. 成人、低幼/儿童、LGBT 示例被过滤，普通电影与剧集保留。
3. “超速”继续保持不可搜索；本功能不为任何站源打开搜索能力。

## 回滚

回滚本任务提交即可恢复原始站源结果，不涉及数据库迁移。
