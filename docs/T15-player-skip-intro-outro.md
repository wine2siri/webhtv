# T15 播放器片头片尾跳过修复

## 本次结论

- 当前发布分支此前没有包含已经完成的本地章节识别代码，因此电视端测试《财神斗战龙》时不会出现自动片头候选，也不会自动跳过。
- 本次把 `3779ad1` 中的公共实现恢复到当前发布分支：Mobile 与 Leanback 共用章节策略，覆盖 Exo、MPV、IJK 的上层播放控制，不修改播放器内核。
- 手工片头/片尾保持最高优先级。自动候选只接受当前文件中明确命名的片头/片尾章节，首次需要用户确认，确认后按当前媒体版本本地保存。
- 片尾不会仅凭时长猜测并强制跳过；只有手工设置或明确章节经用户确认后才执行，避免跳过彩蛋。

## 安全边界

- 无明确章节、直播、未知时长、短片或 IJK 无章节信息时保持原播放，不猜测。
- URL 查询参数不写入本地规则；规则按路径与五秒时长桶区分版本，120 天过期并限制 240 条。
- 自动规则不写入 `History.opening/ending`，不会覆盖或同步用户的手工值。

## 验证

- JVM 策略测试覆盖片头、片尾、边界拒绝和手工优先。
- Mobile 与 Leanback Java 编译作为提交门禁。
- 真机仍需用带有明确具名章节的媒体确认弹窗、确认后的起播 seek，以及切集不串用规则。
